PROJECT: NOTICIARIO

IMPORTANT:
Keep this file updated after every major branch or feature.

Goal:
Noticiario is a Laravel 12 + Inertia + React + TypeScript application for creating short digital news bulletins. The platform helps editors collect and organize news by location/topic, prepare editions, and build scripts. Future phases may include AI-assisted planning, audio/video generation, and publishing automation.

Architecture:
- Laravel 12
- Inertia
- React
- TypeScript
- Tailwind
- MySQL
- Spatie Laravel Permission
- No Blade application pages
- resources/views/app.blade.php is only the Inertia root view
- React pages live in resources/js/Pages
- React layouts live in resources/js/Layouts

Panels:

EDITORIAL SCHEDULES AND MANUAL AI WORKFLOW

New database tables:
- editorial_schedules
  - Defines reusable schedule configurations (daily/weekly/once/custom), editorial context, language/location/category, timing, manual AI mode, and instruction blocks.
- editorial_schedule_runs
  - Represents concrete workflow executions created from schedules and linked to editions/scripts.

Purpose:
- Schedules let editors configure recurring and one-off noticiario planning templates.
- Runs provide the operational unit for each execution cycle (prompt generation, manual AI response capture, and script draft creation).

Manual AI mode workflow:
1. Configure schedule.
2. Create run.
3. Generate prompt.
4. Copy prompt to external AI.
5. Paste AI response.
6. Create script draft.
