PROJECT: NOTICIARIO

## 1. PROJECT OVERVIEW

Project name: Noticiario.

Goal:
Noticiario is a Laravel 13 + Inertia + React + TypeScript platform for creating short digital news bulletins from editorial planning to production-ready scripts.

High-level workflow:
1. Configure bulletin/schedule.
2. Create run.
3. Generate prompt.
4. Generate or paste AI response.
5. Parse response.
6. Create script.
7. Review/fact-check.
8. Verify sources.
9. Approve script.
10. Prepare production metadata.
11. Later audio/video/publishing.

Architecture:
- Laravel 13
- Inertia
- React
- TypeScript
- Tailwind
- MySQL
- Spatie Laravel Permission

Restrictions:
- No Blade application pages.
- resources/views/app.blade.php is only the Inertia root view.
- React pages live in resources/js/Pages.
- React layouts live in resources/js/Layouts.

## TEST DATABASE SAFETY

- Development database is `noticiario2`.
- Test database must be `noticiario2_testing`.
- Tests must be run with:
  - `php artisan test --env=testing`
- Test database can be prepared with:
  - `php artisan migrate:fresh --seed --env=testing`
- Never run `migrate:fresh` without `--env=testing` unless intentionally deleting development data.
- PHPUnit is configured to force testing-safe values including MySQL + `DB_DATABASE=noticiario2_testing`.
- A safety guard in `tests/TestCase.php` blocks test execution when database names are not clearly test databases.
- Guard allows only:
  - `:memory:`
  - names containing `_testing`
  - names ending with `_test`
- Running tests with a non-test database throws:
  - `Refusing to run tests against non-testing database: {database}`
- Command to verify safety:
  - `php artisan noticiario:check-test-database --env=testing`
- Composer safe script:
  - `composer test:safe`
- Recommended MySQL setup command:
  - `CREATE DATABASE IF NOT EXISTS noticiario2_testing CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;`
- `.env.testing` / `.env.testing.example` must use:
  - `DB_DATABASE=noticiario2_testing`
